# Экспорт локального прогресса

В паузе доступен экспорт JSON для личной копии и диагностики:

- Web: «Скачать прогресс (JSON)» → `quiet-harbor-progress.json`.
- Desktop: «Скопировать прогресс (JSON)» → вставить в отдельный текстовый файл.

Экспорт содержит деньги, снасти, садок, коллекцию, заказы, открытия, письма, еду и личную цель. Настройки звука и вибрации в него не входят. Данные не отправляются на сервер, прогресс игры и резервные файлы не меняются. В нормальном режиме копируется текущее состояние памяти, в том числе ещё не записанное после ошибки сохранения.

Это не облачная синхронизация. Импорт из меню **не реализован**; JSON пригоден для ручного восстановления и поддержки, но не означает готового переноса между браузерами. Очистка данных сайта по-прежнему удаляет локальное сохранение. Хранить копию нужно вне браузерного хранилища.

## Более новая схема

Если основной файл, `.tmp` или `.bak` содержит будущую версию, экспорт отдаёт оригинальный текст этого файла. Неизвестные поля и большие числа не проходят через повторную сериализацию. Это важнее экспорта стартовых значений старой игры, которая такой прогресс не понимает. Если защищённый оригинал уже отсутствует, выводится ошибка вместо пустого «сохранения».

## Ограничения проверки

Автотест проверяет состав копии, отсутствие записи/наград, загрузку обратно через `SaveStore`, будущие схемы в трёх расположениях и меню паузы. Графические снимки проверяют раскладку. Web использует официальный API [JavaScriptBridge.download_buffer](https://docs.godotengine.org/en/4.7/classes/class_javascriptbridge.html#class-javascriptbridge-method-download-buffer) непосредственно из нажатия кнопки; браузер может заблокировать скачивание. Поэтому сообщение означает только передачу запроса, не подтверждение сохранения файла. Само скачивание в браузере требует отдельного живого плейтеста.
